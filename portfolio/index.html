Summer 2026Larodec Laboratory, ENSI

AI R&D Intern

Toward AI-Assisted Decomposition of Large Pull Requests into Reviewable Changes

Large pull requests are hard to review. I tested whether a published multi-agent LLM framework could split them into smaller, reviewable changes, using real developer history instead of synthetic benchmarks.

65.0%Atomizer (ICSE 2026) on real Gerrit data
72.4%my taxonomy-routed pipeline
κ = 0.896inter-rater agreement on taxonomy
  • Mined 937,327 Gerrit changes from 7 ecosystems into 142 validated change-split cases, each traced to the developer's own words.
  • Built a taxonomy of why and how developers split changes (κ = 0.896 and 0.769).
  • Diagnosed over-splitting as the main cost driver, then designed a taxonomy-routed pipeline that beat the baseline.
